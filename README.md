# Bachelor-Thesis-Adam-Chudacek
This repository serves as a collection of commands and codes used for my thesis. It includes Python scripts and bash commands used to run externally developed software, process data, and generate analytical visualizations for Ancestral Sequence Reconstruction (ASR) and structural phylogenetics.

## Repository Contents
1. Bash Commands
bash: This file contains all the command-line instructions and pipelines used to execute external bioinformatics tools throughout the project.
2. Python Scripts
### 3di_to_aa_alignment.py
   
#### Description: 
A script designed to translate untrimmed 3Di realignments (generated by tools like FoldMason) back into their corresponding amino acid sequences.  
#### Functionality:
It uses the BioPython library to parse FASTA files, matching 3Di characters to non-gap amino acids while preserving the alignment structure.

### grouped_analysis.py

Description: A data visualization and statistical script for analyzing ezASR .state outputs for Glucokinase (glk) and Aldolase (fbaA).  
PY
Functionality: Parses ancestral nodes to calculate ASR quality, expectation values, and log10 probabilities of absence for specific amino acids (like Tryptophan). It automatically generates 4-panel dashboards, computes Pearson correlations (r, p-values, R 
2
 ) using scipy, and visualizes group abundance comparisons between different evolutionary paths using matplotlib and seaborn.  

### pdb_org_name.py
#### Description:
A utility script for cleaning up and organizing structural database files.  

#### Functionality:
It iterates through a directory of .pdb files, reads the headers to extract ORGANISM_SCIENTIFIC and MOLECULE metadata, sanitizes the strings to remove problematic characters, and renames the files systematically for easier downstream processing.  

### ASR_full_analysis.py
#### Description:
An extensive analytical pipeline focusing on the dynamics of "Early" vs. "Late" amino acids across evolutionary time.  

#### Functionality:
It groups amino acids into defined categories (Early AAs: G, S, Q, N, P, I, L, V, A, T; Late AAs: R, K, H, D, E, C, M, F, Y, W) and calculates their expectation values and mean posterior probabilities from ezASR .state files. Furthermore, it performs sequence resurrection by generating modified FASTA files and exports the calculated presence probabilities into CSV and Markdown tables using pandas.
